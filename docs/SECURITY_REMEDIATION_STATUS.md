**A source fix is not a production security certification.** In particular, the platform now refuses live BOT execution and real outbound handoffs while the model spend, exact-action approval and sender contracts remain unproved. There is no environment-variable switch for this. Demo work remains testable. The public site and the operator platform should not be promoted on the strength of local tests alone.

### Other applicability decisions

The site targets adults acting for businesses; an age gate would collect extra data without a current child-directed service. If a child is actually identified, restrict processing and follow the runbook. No AI chat assistant presently sends first messages; any future chat must identify itself as AI. There is no general public content upload/hosting product, so a DMCA agent registration is not presented as complete. Accessibility source checks and selected browser flows do not establish WCAG 2.1 AA conformance; a keyboard, screen-reader, contrast and assistive-technology audit is a release task. Geist is fetched at build by `next/font` and served locally. Optional analytics scripts are disabled; no ad pixel/session replay is installed by this source. Server providers and any future browser script must be entered in the owner-maintained vendor inventory.
