# Marketing visual direction — 2026-10-06

The homepage uses code-rendered workflow interfaces in place of generated people or job-site photography. This keeps the visual language close to the product, avoids synthetic customer imagery and removes image requests from the page.

## Current homepage visuals

- HeroSystemVisual shows an enquiry moving through Receive → Prepare → Approve → Record.
- CoverageSystemVisual shows residential and commercial work moving through the same operating layer.
- BotWorkflowStory is the interactive demonstration. It uses a fictional account and never sends messages, books appointments, writes to a CRM or calls the BOT runtime.
- Motion is limited to status and handoff indicators using CSS opacity and transforms. Reduced-motion preferences stop it.

The two previous WebP files remain unreferenced in public/media; browsers do not request them and they add no homepage transfer weight. Remove them in a later binary-asset cleanup if desired.

## Future real evidence

Use released photographs only when they show real customers, real jobs or the actual team. Customer photos and quotes should arrive together, with permission. Measured results require a baseline, timeframe and attribution.

The workflow remains labeled illustrative until it is replaced by a verified product recording with fictional demo data. Client logo walls require permission; do not imply partnerships from tool compatibility.
